    21. 선형 자료구조: 스택(LIFO), 큐(FIFO), 덱의 활용¶

    직접 AI 없이 직접 할 수 있어야 하는 항목

    스택과 큐는 "무엇을 먼저 꺼내는가"만 정해 둔 자료구조다. 규칙이 하나뿐이라 단순하지만, 함수 호출, 되돌리기, 작업 대기열, 그래프 탐색처럼 컴퓨터 곳곳에서 쓰인다. 이 항목은 둘을 배열 하나로 만드는 법과 어디에 무엇을 쓰는지를 다룬다. 직접형 항목이므로 배열과 인덱스만으로 AI 없이 짤 수 있어야 한다. 예제는 C다.

    이 항목에서 배우는 것¶

    • 스택(LIFO), 큐(FIFO), 덱이 넣고 꺼내는 쪽을 설명하고, 연산 순서에 따른 결과를 예측할 수 있다.
    • 배열로 스택과 원형 큐를 짜고, 가득 찼을 때와 비었을 때를 처리할 수 있다.
    • 문제를 보고 스택, 큐, 덱 중 맞는 것을 고를 수 있다.

    1. 스택은 나중에 넣은 것부터, 큐는 먼저 넣은 것부터 꺼낸다¶

    직접 해 보기스택, 큐, 덱스택·큐·덱을 골라 넣기와 꺼내기 단추를 눌러 보며, 어느 쪽에서 꺼내지는지와 배열 칸 8개 위에서 head·top 위치가 어떻게 도는지 본다
    새 창에서 크게 열기
    • 스택은 한쪽 끝(top)에서만 넣고 꺼낸다. 마지막에 넣은 것이 먼저 나온다(LIFO, Last In First Out). 접시를 쌓고 위에서부터 집는 모양이다.
    • 큐는 뒤에 넣고 앞에서 꺼낸다. 먼저 넣은 것이 먼저 나온다(FIFO, First In First Out). 줄을 서는 모양이다.
    • 덱(deque, double-ended queue)은 앞과 뒤 양쪽에서 넣고 꺼낸다. 셋 모두 넣기와 꺼내기가 O(1)이다.

    배열로 만든 스택은 top 하나로 충분하다. top은 들어 있는 개수이자 다음에 넣을 칸이다.

    #define CAP 8

int stack[CAP];
int top = 0;

int push(int v) {
    if (top == CAP)
        return 0;            /* 가득 찼다 */
    stack[top++] = v;
    return 1;
}

int pop(int *out) {
    if (top == 0)
        return 0;            /* 비었다 */
    *out = stack[--top];
    return 1;
}

    2. 배열로 만든 큐는 둥글게 돈다¶

    int queue[CAP];
int head = 0, count = 0;     /* head: 맨 앞 칸, count: 들어 있는 개수 */

int enqueue(int v) {
    if (count == CAP)
        return 0;
    queue[(head + count) % CAP] = v;
    count++;
    return 1;
}

int dequeue(int *out) {
    if (count == 0)
        return 0;
    *out = queue[head];
    head = (head + 1) % CAP;
    count--;
    return 1;
}
    • 큐를 그냥 배열로 만들면 앞에서 꺼낼 때마다 나머지를 한 칸씩 당겨야 한다(O(n), 20번(자료구조의 필요성)). 원형 배열은 당기지 않고 head를 옮기며, 끝에 닿으면 % CAP으로 0번 칸에 돌아온다.
    • head와 count를 함께 두면 가득 찬 것(count == CAP)과 빈 것(count == 0)이 바로 구별된다. 앞과 뒤 위치만 두면 둘 다 "앞 == 뒤"가 되어 헷갈리므로, 칸 하나를 늘 비워 두는 방법을 쓰기도 한다.

    3. 짝을 맞출 때는 스택, 차례를 지킬 때는 큐¶

    • 가장 나중에 시작한 일을 가장 먼저 끝내야 하면 스택이다. 괄호 짝 검사, 함수 호출과 복귀(9번(함수 호출과 메모리)의 호출 스택), 되돌리기(Ctrl+Z), 깊이 우선 탐색(27번(그래프 탐색 (DFS·BFS)))이 그렇다.
    • 들어온 차례대로 처리해야 하면 큐다. 프린터 대기열, 키보드 입력 버퍼, 요청 대기열, 너비 우선 탐색(27번(그래프 탐색 (DFS·BFS)))이 그렇다.
    • 양쪽 끝을 다 써야 하면 덱이다. 되돌리기를 최근 100번까지만 기억하는 편집기는 새 작업을 뒤에 넣고 되돌릴 때 뒤에서 꺼내지만(스택처럼), 100개가 넘으면 가장 오래된 것을 앞에서 버린다.

    예측해 보기¶

    문제 1. 1절의 스택으로 무엇이 출력될까?

    int x;
push(1);
push(2);
pop(&x);
printf("%d ", x);
push(3);
push(4);
while (pop(&x))
    printf("%d ", x);
printf("\n");
    정답과 해설

    2 4 3 1. 2를 꺼낸 뒤 스택은 아래부터 1, 3, 4다. 남은 것을 꺼내면 맨 위부터 4, 3, 1이 나온다. 위젯의 스택에서 같은 순서로 눌러 확인할 수 있다.

    문제 2. 2절의 큐(칸 8개, 처음에 비었다)에서 무엇이 출력될까? 둘째 줄을 쓰기 전에 각 값이 몇 번 칸에 있는지 그려 본다.

    int y;
for (int i = 1; i <= 6; i++)
    enqueue(i);
for (int i = 0; i < 4; i++)
    dequeue(&y);
for (int i = 7; i <= 10; i++)
    enqueue(i);
printf("%d %d\n", head, count);
while (dequeue(&y))
    printf("%d ", y);
printf("\n");
    정답과 해설 
    4 6
5 6 7 8 9 10

    1~6은 0~5번 칸에 들어가고, 넷을 꺼내면 head는 4, count는 2다. 7과 8은 6번과 7번 칸에, 9와 10은 끝을 넘어 0번과 1번 칸에 들어간다. 칸 번호가 돌아도 꺼내는 차례는 넣은 차례 그대로다.

    문제 3. 다음 일에는 스택, 큐, 덱 중 무엇이 맞을까? (가) 웹 브라우저의 "뒤로 가기" (나) 여러 사람이 보낸 인쇄 작업 (다) 문자열의 양 끝에서 한 글자씩 떼어 내며 앞뒤가 같은지(회문) 검사하기

    정답과 해설

    (가) 스택, (나) 큐, (다) 덱. 뒤로 가기는 가장 나중에 본 페이지로 먼저 돌아가므로 스택이다. 인쇄 작업은 보낸 차례대로 처리해야 공평하므로 큐다. 회문 검사는 앞과 뒤에서 번갈아 꺼내므로 양쪽 끝을 다 쓰는 덱이다. 무엇을 먼저 꺼내야 하는지 물어보면 고를 수 있다.

    직접 해보기¶

    실습: AI 없이 스택과 큐 쓰기

    1. 문자열의 괄호 (), [], {} 짝이 맞으면 1, 아니면 0을 돌려주는 balanced를 스택으로 짠다. 괄호가 아닌 글자는 건너뛴다.
    2. 2절의 원형 큐에 앞에 넣는 push_front와 뒤에서 꺼내는 pop_back을 더해 덱으로 만든다.
    3. 큐를 연결 리스트로도 짠다. 맨 앞 노드와 맨 끝 노드를 가리키는 포인터를 둘 다 두면 넣기와 꺼내기가 모두 O(1)이 된다(20번(자료구조의 필요성)).
    정답

    1. 예시. 닫는 괄호를 만났는데 스택이 비었거나 맨 위가 짝이 아니면 틀린 것이다. 끝까지 읽은 뒤 스택이 남아 있어도 틀린 것이다.

      int balanced(const char *s) {
    char st[100];
    int n = 0;
    for (; *s != '\0'; s++) {
        char c = *s;
        if (c == '(' || c == '[' || c == '{') {
            if (n == 100)
                return 0;
            st[n++] = c;
        } else if (c == ')' || c == ']' || c == '}') {
            char want = c == ')' ? '(' : c == ']' ? '[' : '{';
            if (n == 0 || st[--n] != want)
                return 0;
        }
    }
    return n == 0;
}

      printf("%d\n", balanced("{[()]}"));         /* 1 */
printf("%d\n", balanced("([)]"));           /* 0 */
printf("%d\n", balanced("(()"));            /* 0: 남은 괄호가 있다 */
printf("%d\n", balanced("())"));            /* 0: 닫을 것이 없다 */
printf("%d\n", balanced("a[i] = f(x);"));   /* 1 */

    2. 예시. 앞에 넣을 때 head를 한 칸 앞으로 옮긴다. C의 %는 나머지에 나누어지는 수의 부호를 붙이므로(C99 표준부터 정해졌다. -1 % 8은 7이 아니라 -1이다) + CAP을 먼저 한다.

      int push_front(int v) {
    if (count == CAP)
        return 0;
    head = (head - 1 + CAP) % CAP;
    queue[head] = v;
    count++;
    return 1;
}

int pop_back(int *out) {
    if (count == 0)
        return 0;
    count--;
    *out = queue[(head + count) % CAP];
    return 1;
}

      int z;
push_front(1);
push_front(2);
enqueue(3);                        /* 앞에서부터 2 1 3 */
pop_back(&z);
printf("%d\n", z);                 /* 3 */
dequeue(&z);
printf("%d\n", z);                 /* 2 */
pop_back(&z);
printf("%d\n", z);                 /* 1 */

    3. 예시. 넣을 때는 끝 노드의 next에 새 노드를 달고 끝 포인터를 옮긴다. 꺼낼 때는 맨 앞 노드를 떼어 free한다. 빈 큐에 넣을 때는 앞 포인터도 새 노드를 가리키게 하고, 마지막 하나를 꺼내면 끝 포인터도 NULL로 되돌린다. 뒤의 것을 빠뜨리면 비운 뒤에 다시 넣을 때 이미 free한 노드에 새 노드를 단다.

      struct qnode {
    int value;
    struct qnode *next;
};

struct qnode *front = NULL, *back = NULL;

int list_enqueue(int v) {
    struct qnode *n = malloc(sizeof(struct qnode));
    if (n == NULL)
        return 0;
    n->value = v;
    n->next = NULL;
    if (back == NULL)
        front = n;                 /* 비어 있었다 */
    else
        back->next = n;
    back = n;
    return 1;
}

int list_dequeue(int *out) {
    if (front == NULL)
        return 0;                  /* 비었다 */
    struct qnode *n = front;
    *out = n->value;
    front = n->next;
    if (front == NULL)
        back = NULL;               /* 마지막 하나를 꺼냈다 */
    free(n);
    return 1;
}

      int w;
list_enqueue(1);
list_enqueue(2);
list_dequeue(&w);
printf("%d\n", w);                 /* 1 */
list_dequeue(&w);
printf("%d\n", w);                 /* 2 */
printf("%d\n", list_dequeue(&w));  /* 0: 비었다 */
list_enqueue(3);                   /* 비운 뒤에 다시 넣는다 */
list_dequeue(&w);
printf("%d\n", w);                 /* 3 */

    AI와 함께 확인하기¶

    AI 활용 과제: 원형 덱의 경계 검사

    1. AI에게 "C로 칸 8개짜리 원형 배열 덱(앞뒤로 넣고 꺼내기)"을 짜 달라고 한다.
    2. 실행하기 전에 다음 경우의 결과를 적는다. 빈 덱에서 push_front 한 번, 8개를 넣은 뒤 9번째 넣기, 넣고 꺼내기를 20번 넘게 되풀이하기.
    3. 실행해 대조한다. 틀리면 실행 결과를 보여 주고 고치게 한다.
    확인할 점

    • head = (head - 1) % CAP처럼 쓴 코드가 흔하다. C에서는 head가 0이면 -1이 되어 queue[-1], 배열 밖에 쓴다. 이 PC의 MSVC에서 확인한 값이다.

      printf("%d\n", -1 % 8);            /* -1 */
printf("%d\n", (-1 + 8) % 8);      /* 7 */

    • 앞과 뒤 위치만 두고 "같으면 비었다"고 하는 코드는 8개를 다 채웠을 때도 같아져서, 가득 찬 덱을 빈 것으로 본다. 개수를 따로 세거나 칸 하나를 비워 두는지 본다.

    • 가득 찼을 때 넣기, 비었을 때 꺼내기가 실패를 알리는지 본다. 아무 말 없이 덮어쓰거나 쓰레기 값을 돌려주면 안 된다.

    더 알아보기¶

    다른 언어의 스택과 큐

    대부분의 언어가 스택과 큐를 기본으로 준다. C#은 Stack<T>, Queue<T>, Python은 덱인 collections.deque를 쓴다. Python의 list로 큐를 만들면 앞에서 꺼내는 pop(0)이 나머지를 모두 당기므로 O(n)이다. 앞에서 꺼내는 일이 많으면 deque의 popleft()를 쓴다.

    정리¶

    • 스택은 나중에 넣은 것부터(LIFO), 큐는 먼저 넣은 것부터(FIFO), 덱은 양쪽에서 넣고 꺼낸다. 모두 O(1)이다.
    • 배열로 만든 큐는 head와 count, % CAP으로 둥글게 돌려 앞을 비운 칸을 다시 쓴다. 가득 찬 경우와 빈 경우를 꼭 검사한다.
    • 가장 나중에 시작한 것을 먼저 끝내면 스택, 들어온 차례대로 처리하면 큐를 쓴다.

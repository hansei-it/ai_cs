    23. 트리와 이진 탐색 트리(BST): 탐색과 불균형 문제¶

    직접 AI 없이 직접 할 수 있어야 하는 항목

    연결 리스트는 노드마다 다음 노드 하나를 가리켰다(20번(자료구조의 필요성)). 노드가 자식 둘을 가리키게 하면 이진 트리가 되고, "작은 키는 왼쪽, 큰 키는 오른쪽"이라는 규칙을 더하면 이진 탐색 트리(BST)가 된다. 정렬된 배열처럼 반씩 줄여 가며 찾으면서도, 배열과 달리 밀지 않고 넣을 수 있다. 다만 넣는 차례가 나쁘면 연결 리스트만큼 느려진다. 직접형 항목이므로 넣기, 찾기, 지우기를 AI 없이 짜고 트리를 손으로 그릴 수 있어야 한다. 예제는 C다.

    이 항목에서 배우는 것¶

    • 키를 넣는 차례대로 BST를 그리고, 찾을 때 거치는 노드를 따라갈 수 있다.
    • 찾기가 트리의 높이만큼 걸린다는 것과, 넣는 차례에 따라 높이가 log n에서 n까지 달라진다는 것을 설명할 수 있다.
    • 순회로 키를 정렬된 차례로 꺼내고, 노드를 지우고 돌려주는 코드를 짤 수 있다.

    1. 작으면 왼쪽, 크거나 같으면 오른쪽¶

    직접 해 보기이진 탐색 트리 실험실넣을 차례를 골라 키를 하나씩 넣으며 트리 모양과 높이가 어떻게 달라지는지 보고, 키를 찾아 몇 번 비교하는지 센다
    새 창에서 크게 열기 
    struct node {
    int key;
    struct node *left, *right;
};

struct node *insert(struct node *root, int key) {
    if (root == NULL) {                          /* 빈자리에 새 노드 */
        struct node *n = malloc(sizeof(struct node));
        if (n == NULL)
            return NULL;
        n->key = key;
        n->left = n->right = NULL;
        return n;
    }
    if (key < root->key)
        root->left = insert(root->left, key);
    else
        root->right = insert(root->right, key);
    return root;
}

struct node *search(struct node *p, int key) {
    while (p != NULL && p->key != key)
        p = key < p->key ? p->left : p->right;
    return p;                                    /* 없으면 NULL */
}
    • 모든 노드에서 왼쪽 아래의 키는 모두 그 노드보다 작고, 오른쪽 아래의 키는 모두 크거나 같다. 찾을 때는 뿌리에서 출발해 비교 한 번마다 왼쪽이나 오른쪽 하나만 남긴다.
    • 넣기도 같은 길을 따라 내려가 빈자리(NULL)에 새 노드를 단다. 배열처럼 다른 키를 밀지 않는다.

    2. 찾기는 높이만큼 걸리고, 높이는 넣는 차례가 정한다¶

    • 찾기와 넣기는 뿌리에서 잎까지 한 길만 내려가므로, 많아야 높이(층 수)만큼 비교한다.
    • 키를 무작위 차례로 넣으면 높이가 log n에 비례해 자란다. 10만 개에서 40층이었다. 정렬된 차례로 넣으면 모든 노드가 오른쪽으로만 달려 높이가 n이 되고, 연결 리스트와 같아진다. 10만 개에서 찾기가 약 3,000배 느렸다.
    • 그래서 실제로 쓰는 트리는 넣고 지울 때마다 모양을 고쳐 높이를 log n으로 지키는 균형 트리(레드블랙 트리, AVL 트리 등)다.

    3. 중위 순회는 정렬된 차례로 꺼낸다¶

    void print_inorder(const struct node *p) {       /* 왼쪽 → 나 → 오른쪽 */
    if (p == NULL)
        return;
    print_inorder(p->left);
    printf("%d ", p->key);
    print_inorder(p->right);
}

void free_tree(struct node *p) {                 /* 왼쪽 → 오른쪽 → 나 */
    if (p == NULL)
        return;
    free_tree(p->left);
    free_tree(p->right);
    free(p);                                     /* 자식을 다 돌려준 뒤에 나를 */
}
    • 왼쪽 아래는 모두 작고 오른쪽 아래는 모두 크므로, "왼쪽, 나, 오른쪽" 차례로 방문하면 작은 키부터 정렬된 차례로 나온다. 해시 테이블(22번(해시 테이블))과 달리 BST는 차례가 있는 일(정렬해 출력하기, 범위 안의 키 찾기)을 잘한다.
    • 트리를 돌려줄 때는 자식을 먼저 돌려주는 후위 순회를 쓴다. 나를 먼저 free하면 자식의 주소를 잃는다.

    예측해 보기¶

    문제 1. 무엇이 출력될까? 트리를 먼저 그리고, 위젯의 세 번째 차례로 확인한다.

    #include <stdio.h>
#include <stdlib.h>

struct node {
    int key;
    struct node *left, *right;
};

struct node *insert(struct node *root, int key) {
    if (root == NULL) {
        struct node *n = malloc(sizeof(struct node));
        if (n == NULL)
            return NULL;
        n->key = key;
        n->left = n->right = NULL;
        return n;
    }
    if (key < root->key)
        root->left = insert(root->left, key);
    else
        root->right = insert(root->right, key);
    return root;
}

int height(const struct node *p) {
    if (p == NULL)
        return 0;
    int l = height(p->left), r = height(p->right);
    return 1 + (l > r ? l : r);
}

int main(void) {
    int keys[] = { 40, 20, 60, 10, 30, 50, 70, 25, 55 };
    struct node *root = NULL;
    for (int i = 0; i < 9; i++)
        root = insert(root, keys[i]);
    printf("%d\n", height(root));
    printf("%d\n", root->left->right->left->key);
    return 0;
}
    정답과 해설 
    4
25

    처음 일곱 키는 40을 뿌리로 3층을 꽉 채운다. 25는 40보다 작고 20보다 크고 30보다 작아서 30의 왼쪽, 55는 50의 오른쪽에 달려 4층이 생긴다. root->left->right->left는 40에서 왼쪽(20), 오른쪽(30), 왼쪽(25)이다.

    문제 2. 1부터 1000까지를 차례대로 넣은 BST에서 500을 찾으면 몇 번 비교할까? 1을 찾으면? 같은 키를 무작위 차례로 넣으면 평균 몇 번쯤일까?

    정답과 해설

    500. 정렬된 차례로 넣으면 노드마다 오른쪽 자식만 생겨 뿌리 1부터 1, 2, 3, …, 1000이 한 줄로 달린다. 500은 위에서 500번째라 500번 비교하고, 1은 뿌리라 1번에 찾는다. 키 1,000개를 모두 한 번씩 찾으면 평균 500.5번이다. 같은 키 1,000개를 무작위 차례로 넣었더니(아래 측정 프로그램) 높이가 21층이었고, 키 하나를 찾는 데 평균 11.77번 비교했다. 같은 키라도 넣는 차례가 시간을 정한다.

    직접 해보기¶

    실습: AI 없이 BST 짜기

    1. 1절의 insert와 3절의 순회로 BST를 만들고, 문제 1의 키를 넣어 중위 순회로 출력한다. 높이도 출력한다.
    2. 키가 lo 이상 hi 이하인 노드 수를 세는 count_range를 짠다. 범위 밖이 분명한 쪽 가지는 내려가지 않는다.
    3. 키를 지우는 remove_key를 짠다. 지울 노드의 자식이 0개, 1개, 2개인 세 경우를 따로 그려 본 뒤 짠다. 자식이 2개면 오른쪽 아래에서 가장 작은 키(바로 다음 키)를 그 자리로 옮기고, 옮긴 노드를 지운다.
    정답

    예시. 아래 프로그램의 출력은 코드 바로 밑에 있다.

    #include <stdio.h>
#include <stdlib.h>

struct node {
    int key;
    struct node *left, *right;
};

struct node *insert(struct node *root, int key) {
    if (root == NULL) {
        struct node *n = malloc(sizeof(struct node));
        if (n == NULL)
            return NULL;
        n->key = key;
        n->left = n->right = NULL;
        return n;
    }
    if (key < root->key)
        root->left = insert(root->left, key);
    else
        root->right = insert(root->right, key);
    return root;
}

int height(const struct node *p) {
    if (p == NULL)
        return 0;
    int l = height(p->left), r = height(p->right);
    return 1 + (l > r ? l : r);
}

void print_inorder(const struct node *p) {
    if (p == NULL)
        return;
    print_inorder(p->left);
    printf("%d ", p->key);
    print_inorder(p->right);
}

int count_range(const struct node *p, int lo, int hi) {
    if (p == NULL)
        return 0;
    if (p->key < lo)                       /* 왼쪽 아래는 더 작으니 볼 필요 없다 */
        return count_range(p->right, lo, hi);
    if (p->key > hi)
        return count_range(p->left, lo, hi);
    return 1 + count_range(p->left, lo, hi) + count_range(p->right, lo, hi);
}

struct node *remove_key(struct node *root, int key) {
    if (root == NULL)
        return NULL;
    if (key < root->key)
        root->left = remove_key(root->left, key);
    else if (key > root->key)
        root->right = remove_key(root->right, key);
    else if (root->left == NULL || root->right == NULL) {      /* 자식이 0개나 1개 */
        struct node *child = root->left != NULL ? root->left : root->right;
        free(root);
        return child;                      /* 하나 남은 자식이 그 자리를 잇는다 */
    } else {                               /* 자식이 2개 */
        struct node *next = root->right;
        while (next->left != NULL)
            next = next->left;             /* 오른쪽 아래에서 가장 작은 키 */
        root->key = next->key;
        root->right = remove_key(root->right, next->key);
    }
    return root;
}

void free_tree(struct node *p) {
    if (p == NULL)
        return;
    free_tree(p->left);
    free_tree(p->right);
    free(p);
}

int main(void) {
    int keys[] = { 40, 20, 60, 10, 30, 50, 70, 25, 55 };
    struct node *root = NULL;
    for (int i = 0; i < 9; i++)
        root = insert(root, keys[i]);
    print_inorder(root);
    printf("\n");
    printf("%d\n", height(root));
    printf("%d\n", count_range(root, 25, 55));
    root = remove_key(root, 10);           /* 잎 */
    root = remove_key(root, 30);           /* 자식 하나(25) */
    root = remove_key(root, 40);           /* 자식 둘인 뿌리 */
    print_inorder(root);
    printf("\n");
    printf("%d\n", root->key);
    free_tree(root);
    return 0;
}

50
    • count_range(root, 25, 55)는 25, 30, 40, 50, 55의 5개다.
    • 뿌리 40을 지우면 오른쪽 아래에서 가장 작은 50이 뿌리 자리로 올라가고, 원래 50의 자리는 그 자식 55가 잇는다. 중위 순회가 여전히 정렬된 차례인지가 지우기를 맞게 짰는지 보는 첫 확인이다.

    AI와 함께 확인하기¶

    AI 활용 과제: BST 판정 함수 시험하기

    1. AI에게 "주어진 이진 트리가 이진 탐색 트리인지 판정하는 C 함수"를 짜 달라고 한다.
    2. 넣기 함수를 쓰지 않고 노드를 직접 이어 다음 트리를 만든다. 뿌리 50의 왼쪽 자식이 30이고, 30의 오른쪽 자식이 60이다. 실행하기 전에 판정 결과를 적는다.
    3. 실행해 대조한다. 틀리면 이 트리를 보여 주고 고치게 한다.
    확인할 점
    • 이 트리는 BST가 아니다. 60이 50의 왼쪽 아래에 있으니 50보다 작아야 한다. 그런데 "왼쪽 자식은 나보다 작고 오른쪽 자식은 나보다 크다"만 보는 함수는 50-30, 30-60의 각 쌍이 규칙에 맞아서 BST라고 답한다.

    • 맞는 판정은 내려가면서 "이 아래 키가 있어야 할 범위"를 함께 넘긴다. 왼쪽으로 가면 위 노드의 키가 상한, 오른쪽으로 가면 하한이 된다. 중위 순회 결과가 정렬된 차례인지 보는 방법도 있다.

      int is_bst(const struct node *p, long long lo, long long hi) {
    if (p == NULL)
        return 1;
    if (p->key < lo || p->key >= hi)          /* 범위: lo 이상, hi 미만 */
        return 0;
    return is_bst(p->left, lo, p->key) && is_bst(p->right, p->key, hi);
}

int is_bst_local(const struct node *p) {     /* 자식만 보는 틀린 판정 */
    if (p == NULL)
        return 1;
    if (p->left != NULL && p->left->key >= p->key)
        return 0;
    if (p->right != NULL && p->right->key < p->key)
        return 0;
    return is_bst_local(p->left) && is_bst_local(p->right);
}

      struct node c = { 60, NULL, NULL }, b = { 30, NULL, &c }, a = { 50, &b, NULL };
printf("%d\n", is_bst_local(&a));                         /* 1: 틀린 판정 */
printf("%d\n", is_bst(&a, -2147483648LL, 2147483648LL));  /* 0 */

    더 알아보기¶

    재귀와 깊은 트리

    이 항목의 넣기, 높이, 순회는 재귀로 짰다. 균형 잡힌 트리는 깊이가 log n이라 괜찮지만, 정렬된 차례로 넣은 10만 개짜리 트리는 깊이가 10만이라 재귀가 스택을 넘칠 수 있다. 9번(함수 호출과 메모리)의 재귀 함수는 Debug 빌드에서 깊이 약 3,580에서 넘쳤다. 넘치는 깊이는 함수가 쓰는 지역 변수의 크기와 빌드 설정에 따라 다르다. 아래 측정 프로그램은 그래서 넣기와 높이를 반복문으로 짰다. 균형 트리를 쓰면 이 걱정도 함께 사라진다.

    이 항목의 측정 방법

    이 PC(Core i9-14900KF, DDR5 64GB)에서 0부터 n−1까지의 정수를 무작위로 섞은 차례와 정렬된 차례로 BST에 넣고, 높이와 모든 키를 한 번씩 찾는 시간을 쟀다. 아래 프로그램을 cl /O2로 빌드해 경우마다 5번 실행했다. 높이와 평균 비교 수는 다섯 번 모두 같았다(무작위 1,000개 평균 11.77번, 1만 개 15.71번, 10만 개 20.52번). 만드는 시간은 10만 개에서 무작위 차례가 10.9~14.1ms, 정렬된 차례가 9,424~10,213ms였다.

    /* 23번 측정: 넣는 차례(무작위 / 정렬)에 따른 BST의 높이, 만드는 시간, 평균 비교 수와 찾기 시간
   usage: bstm.exe <0 무작위 | 1 정렬> <n> */
#include <stdio.h>
#include <stdlib.h>
#include <windows.h>

struct node { int key; struct node *left, *right; };

static unsigned int seed = 99;
static unsigned int rnd(void) { seed ^= seed << 13; seed ^= seed >> 17; seed ^= seed << 5; return seed; }

static double now_ms(void) {
    static LARGE_INTEGER f; LARGE_INTEGER c;
    if (!f.QuadPart) QueryPerformanceFrequency(&f);
    QueryPerformanceCounter(&c);
    return (double)c.QuadPart * 1000.0 / (double)f.QuadPart;
}

static struct node *insert(struct node *root, int key) {   /* 재귀 없이 넣는다 */
    struct node *n = malloc(sizeof *n);
    n->key = key; n->left = n->right = NULL;
    if (root == NULL) return n;
    struct node *p = root;
    for (;;) {
        if (key < p->key) { if (p->left) p = p->left; else { p->left = n; break; } }
        else { if (p->right) p = p->right; else { p->right = n; break; } }
    }
    return root;
}

static int find_count(struct node *p, int key) {           /* 비교한 노드 수 */
    int c = 0;
    while (p) { c++; if (key == p->key) return c; p = key < p->key ? p->left : p->right; }
    return c;
}

static int height(struct node *root, int n) {               /* 층 수, 스택 없이 너비 우선으로 센다 */
    struct node **q = malloc(sizeof(struct node *) * n);
    int head = 0, tail = 0, h = 0;
    if (root) q[tail++] = root;
    while (head < tail) {
        int level = tail - head;
        h++;
        for (int i = 0; i < level; i++) {
            struct node *p = q[head++];
            if (p->left) q[tail++] = p->left;
            if (p->right) q[tail++] = p->right;
        }
    }
    free(q);
    return h;
}

int main(int argc, char **argv) {
    int mode = atoi(argv[1]), n = atoi(argv[2]);
    int *keys = malloc(sizeof(int) * n);
    for (int i = 0; i < n; i++) keys[i] = i;
    if (mode == 0)
        for (int i = n - 1; i > 0; i--) { int j = rnd() % (i + 1), t = keys[i]; keys[i] = keys[j]; keys[j] = t; }
    double t0 = now_ms();
    struct node *root = NULL;
    for (int i = 0; i < n; i++) root = insert(root, keys[i]);
    double t1 = now_ms();
    long long total = 0;
    double t2 = now_ms();
    for (int i = 0; i < n; i++) total += find_count(root, i);
    double t3 = now_ms();
    printf("%s n=%d height=%d build=%.1f ms avg_compare=%.2f find=%.1f ns\n", mode ? "sorted" : "random", n, height(root, n),
           t1 - t0, (double)total / n, (t3 - t2) * 1e6 / n);
    return 0;
}

    정리¶

    • BST는 작은 키를 왼쪽, 크거나 같은 키를 오른쪽에 둔다. 찾기와 넣기는 뿌리에서 한 길만 내려가므로 높이만큼 걸린다.
    • 높이는 넣는 차례가 정한다. 무작위 차례면 log n, 정렬된 차례면 n이다. 실제로는 높이를 log n으로 지키는 균형 트리를 쓴다.
    • 중위 순회는 키를 정렬된 차례로 꺼내고, 트리를 돌려줄 때는 후위 순회로 자식부터 free한다.

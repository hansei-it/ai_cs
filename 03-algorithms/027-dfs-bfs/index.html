    27. 그래프 탐색: 깊이 우선 탐색(DFS)과 너비 우선 탐색(BFS)¶

    직접 AI 없이 직접 할 수 있어야 하는 항목

    그래프(25번(그래프의 표현 방식))에서 "여기서 저기까지 갈 수 있나?", "가장 짧은 길은?", "서로 이어진 무리가 몇 개인가?"를 답하려면 꼭짓점을 빠짐없이 한 번씩 방문해야 한다. 그 방법이 탐색이다. 깊이 우선 탐색(DFS)과 너비 우선 탐색(BFS)은 다음에 갈 곳을 스택에 두느냐 큐에 두느냐가 핵심 차이다(21번(선형 자료구조)). 미로 찾기, 웹 크롤러, 패키지 설치 순서, 게임의 길 찾기가 모두 이 위에 있다. 직접형 항목이므로 두 탐색을 AI 없이 짜고, 방문 차례를 손으로 따라갈 수 있어야 한다. 예제는 Python이다.

    이 항목에서 배우는 것¶

    • 같은 그래프에서 DFS와 BFS의 방문 차례를 손으로 구할 수 있다.
    • DFS는 스택(또는 재귀), BFS는 큐로 짜고, 방문 표시를 빠뜨리면 생기는 일을 설명할 수 있다.
    • BFS로 간선 수로 잰 최단 거리와 경로를 구할 수 있다.

    1. DFS는 한 길을 끝까지, BFS는 가까운 곳부터¶

    직접 해 보기미로 탐색: DFS와 BFSDFS와 BFS를 골라 미로를 한 단계씩 탐색하며, 스택과 큐에 든 칸, 방문한 칸의 수, 찾은 경로의 길이를 비교한다. 칸을 눌러 벽을 바꿀 수도 있다
    새 창에서 크게 열기
    • DFS는 갈 수 있는 한 길로 끝까지 가 보고, 막히면 마지막 갈림길로 돌아와 다른 길을 간다. 미로에서 G에 닿기까지 BFS보다 적은 칸을 방문했지만, 찾은 길은 20걸음으로 가장 짧은 길(14걸음)이 아니었다.
    • BFS는 출발점에서 가까운 칸부터 물결처럼 넓혀 간다. 방문한 칸은 많았지만, 처음 닿은 길이 언제나 가장 짧다.
    • 둘 다 꼭짓점과 간선을 한 번씩 보므로 인접 리스트에서 O(V + E)다.

    2. 스택을 쓰면 DFS, 큐를 쓰면 BFS¶

    from collections import deque

graph = {1: [2, 3], 2: [1, 4, 5], 3: [1, 6], 4: [2], 5: [2, 6], 6: [3, 5]}

def dfs(g, u, visited):
    visited.append(u)                 # 방문 표시
    for v in g[u]:
        if v not in visited:
            dfs(g, v, visited)        # 재귀 호출이 스택 노릇을 한다
    return visited

def bfs(g, s):
    visited = [s]
    q = deque([s])
    while q:
        u = q.popleft()               # 큐의 앞에서 꺼낸다
        for v in g[u]:
            if v not in visited:
                visited.append(v)     # 큐에 넣을 때 방문 표시
                q.append(v)
    return visited

print(dfs(graph, 1, []))   # [1, 2, 4, 5, 6, 3]
print(bfs(graph, 1))       # [1, 2, 3, 4, 5, 6]
    • DFS의 재귀는 함수 호출 스택(9번(함수 호출과 메모리))에 "돌아올 곳"을 쌓는 일이다. 가장 나중에 들어간 길에서 먼저 돌아온다. BFS는 큐에 넣은 차례대로 꺼내므로 가까운 꼭짓점부터 방문한다.
    • 재귀 대신 리스트를 스택으로 쓸 때는 bfs의 popleft()를 pop()으로만 바꾸면 안 된다. 넣을 때 방문 표시를 하면 [1, 2, 3, 6, 5, 4]가 나와 그림의 DFS 차례와 다르다. 꺼낼 때 방문 표시를 하고 이웃을 거꾸로 넣는다(실습 3).
    • 방문 표시가 없으면 탐색이 끝나지 않는다. 무향 그래프에서는 간선 하나만으로도 1 → 2 → 1 → …로 되돌아가고, 방향 그래프에서는 사이클이 있으면 같은 꼭짓점을 끝없이 다시 방문한다. 여기서는 차례를 보이려고 visited를 리스트로 두었지만, in 검사가 O(n)이라 큰 그래프에서는 set을 쓴다.

    3. BFS는 간선 수로 잰 최단 거리를 준다¶

    def shortest(g, s):
    dist = {s: 0}
    q = deque([s])
    while q:
        u = q.popleft()
        for v in g[u]:
            if v not in dist:
                dist[v] = dist[u] + 1     # 처음 닿았을 때의 거리가 최단 거리
                q.append(v)
    return dist

print(shortest(graph, 1))   # {1: 0, 2: 1, 3: 1, 4: 2, 5: 2, 6: 2}
    • BFS는 거리가 d인 꼭짓점을 모두 꺼낸 뒤에야 거리 d+1인 꼭짓점을 꺼낸다. 그래서 어떤 꼭짓점에 처음 닿았을 때의 거리가 가장 적은 간선 수다. 거리를 적을 때 "어디서 왔는지"도 함께 적어 두면 경로를 거꾸로 따라가 복원할 수 있다(아래 실습 1).
    • DFS로는 최단 거리를 보장하지 못한다. 대신 "갈 수 있나?", "이어진 무리가 몇 개인가?", 사이클 찾기처럼 끝까지 가 보는 문제에 잘 맞는다.
    • 간선마다 거리가 다르면(가중치 그래프) BFS 대신 다익스트라 알고리즘을 쓴다. 큐 대신 우선순위 큐(24번(힙과 우선순위 큐))에서 지금까지 가장 가까운 꼭짓점을 꺼낸다.

    예측해 보기¶

    문제 1. 2절의 dfs와 bfs로 방향 그래프를 탐색한다. 무엇이 출력될까?

    links = {"A": ["B", "C"], "B": ["D"], "C": ["D", "E"], "D": ["F"], "E": ["F"], "F": []}
print(dfs(links, "A", []))
print(bfs(links, "A"))
    정답과 해설 
    ['A', 'B', 'D', 'F', 'C', 'E']
['A', 'B', 'C', 'D', 'E', 'F']

    DFS는 A에서 B, D, F까지 내려갔다가 막히면 A로 돌아와 C를 간다. C의 이웃 D는 이미 방문했으니 E로 가고, E의 이웃 F도 이미 방문했다. BFS는 A의 이웃 B, C를 먼저, 그다음 그들의 이웃 D, E, 마지막에 F를 방문한다.

    문제 2. 꼭짓점 2,000개가 한 줄로 이어진 그래프를 2절의 재귀 dfs로 탐색한다. 두 번째 print는 무엇을 출력할까?

    import sys

chain = {i: [i + 1] for i in range(1999)}
chain[1999] = []
print(sys.getrecursionlimit())   # 1000
print(len(dfs(chain, 0, [])))
    정답과 해설

    출력하지 못하고 RecursionError로 멈춘다. Python은 재귀 깊이를 기본 1,000으로 막아 둔다. 한 줄로 이어진 2,000개를 재귀로 따라가면 깊이가 2,000이라 그 전에 멈춘다. C에는 이런 제한이 없어 깊이 2,000쯤은 이 PC에서 Debug 빌드로도 버텼지만, 깊이가 더 깊어지면 1MiB 스택이 넘쳐 프로그램이 죽는다(9번(함수 호출과 메모리)). 깊이를 알 수 없는 그래프는 아래 실습 3처럼 반복문과 직접 만든 스택으로 탐색한다.

    직접 해보기¶

    실습: AI 없이 탐색 짜기

    1. 위젯의 미로에서 S부터 G까지 가장 짧은 걸음 수와 그 경로를 BFS로 구한다. 칸마다 어디서 왔는지(parent)를 적어 두고, G에서 거꾸로 따라가 경로를 만든다.
    2. 무향 그래프에서 서로 이어진 무리(연결 요소)가 몇 개인지 센다. 아직 방문하지 않은 꼭짓점에서 탐색을 시작할 때마다 하나씩 센다.
    3. 2절의 재귀 dfs를 재귀 없이 리스트를 스택으로 써서 다시 짠다. 방문 차례가 재귀판과 같은지 확인하고, 문제 2의 2,000개짜리 그래프도 탐색해 본다.
    정답

    예시.

    MAZE = [
    "S...#....",
    "##.#..##.",
    "...#.#...",
    ".#...#.#.",
    ".#.###.#.",
    ".#.....#.",
    "...###..G",
]

def find(ch):
    for r, row in enumerate(MAZE):
        if ch in row:
            return (r, row.index(ch))

def maze_path(start, goal):
    parent = {start: None}
    q = deque([start])
    while q:
        r, c = q.popleft()
        if (r, c) == goal:
            break
        for dr, dc in ((-1, 0), (0, 1), (1, 0), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < len(MAZE) and 0 <= nc < len(MAZE[0]) and MAZE[nr][nc] != "#" and (nr, nc) not in parent:
                parent[(nr, nc)] = (r, c)
                q.append((nr, nc))
    path, cur = [], goal
    while cur is not None:            # G에서 거꾸로 따라간다
        path.append(cur)
        cur = parent[cur]
    return path[::-1]

p = maze_path(find("S"), find("G"))
print(len(p) - 1)                     # 14
print(p[:4])                          # [(0, 0), (0, 1), (0, 2), (1, 2)]

def count_components(g):
    seen, count = set(), 0
    for s in g:
        if s not in seen:
            count += 1
            seen.update(bfs(g, s))
    return count

groups = {1: [2], 2: [1], 3: [4, 5], 4: [3], 5: [3], 6: []}
print(count_components(groups))       # 3

def dfs_stack(g, s):
    visited, stack = [], [s]
    while stack:
        u = stack.pop()               # 스택의 뒤에서 꺼낸다
        if u in visited:
            continue
        visited.append(u)
        for v in reversed(g[u]):      # 첫 이웃이 먼저 나오도록 거꾸로 넣는다
            if v not in visited:
                stack.append(v)
    return visited

print(dfs_stack(graph, 1))            # [1, 2, 4, 5, 6, 3]
print(len(dfs_stack(chain, 0)))       # 2000
    • 실습 1에서 구한 S부터 G까지의 경로 길이는 위젯의 BFS 결과와 같은 14걸음이다.
    • 3에서 이웃을 그대로 넣으면 마지막 이웃부터 꺼내져서 방문 차례가 재귀판과 달라진다. 둘 다 올바른 DFS이지만 차례를 맞추려면 거꾸로 넣는다.

    AI와 함께 확인하기¶

    AI 활용 과제: 격자 미로 최단 거리 판정하기

    1. AI에게 "문자열 리스트로 된 격자 미로(#은 벽)에서 S부터 G까지의 최단 걸음 수를 BFS로 구하고, 길이 없으면 -1을 돌려주는 Python 함수"를 짜 달라고 한다.
    2. 아래 미로의 답을 먼저 적는다. S와 G 사이는 벽으로 막혀 있다.
    3. 실행해 대조한다. 다르면 이 미로를 보여 주고 고치게 한다.
    S.#
###
G..
    확인할 점

    • 답은 -1이다. 그런데 이웃 칸이 격자 안인지 확인할 때 nr < len(grid)처럼 위쪽 끝만 보고 0 <= nr을 빠뜨리면, S에서 위로 간 grid[-1]이 Python에서는 마지막 줄이 되어 G에 1걸음 만에 닿는다. C라면 배열 밖을 읽어 이상한 값이 나왔을 실수가, Python에서는 오류 없이 엉뚱한 답이 된다.

      grid = ["S.#", "###", "G.."]
print(grid[-1][0])       # G

    • 방문 표시를 큐에서 꺼낼 때 하면 같은 칸이 큐에 여러 번 들어간다. 답은 맞아도 큰 미로에서 느려진다. 넣을 때 표시하는지 본다.

    • S나 G가 없는 미로, S와 G가 같은 칸인 미로에서도 돌려 본다.

    더 알아보기¶

    DFS로 하는 위상 정렬

    방향 그래프에서 "A를 하려면 B가 먼저"처럼 차례가 있는 일(수강 신청의 선수 과목, 패키지 설치 순서, 빌드 순서)을 늘어놓는 것을 위상 정렬이라 한다. DFS에서 한 꼭짓점의 탐색이 끝나는 차례를 거꾸로 하면 위상 정렬이 된다. 사이클이 있으면 차례를 정할 수 없고, DFS 중에 "아직 끝나지 않은 꼭짓점"을 다시 만나면 사이클이 있다는 뜻이다. 패키지 관리자(17번(패키지 생태계와 의존성 관리))가 의존성의 순환을 찾아내는 방법 중 하나다.

    정리¶

    • DFS는 스택(또는 재귀)으로 한 길을 끝까지, BFS는 큐로 가까운 곳부터 방문한다. 둘 다 O(V + E)이고, 방문 표시가 없으면 무향 그래프의 간선이나 사이클에서 끝나지 않는다.
    • BFS는 처음 닿았을 때의 거리가 간선 수로 잰 최단 거리다. parent를 적어 두면 경로를 복원한다.
    • 깊이를 알 수 없는 그래프는 재귀 대신 직접 만든 스택을 쓴다. Python에서는 음수 인덱스가 오류 없이 뒤쪽 칸을 가리키니 격자 경계를 양쪽 다 검사한다.

    25. 그래프의 표현 방식: 인접 행렬 vs 인접 리스트¶

    직접 AI 없이 직접 할 수 있어야 하는 항목

    지도에서 길 찾기, SNS의 친구 추천, 웹 페이지의 링크, 패키지 사이의 의존성(17번(패키지 생태계와 의존성 관리))은 모두 "무엇과 무엇이 이어져 있다"는 관계다. 이런 관계를 담는 자료구조가 그래프다. 같은 그래프도 행렬로 담느냐 목록으로 담느냐에 따라 빠른 질문과 차지하는 메모리가 크게 다르다. 직접형 항목이므로 간선 목록에서 두 표현을 AI 없이 만들고 서로 바꿀 수 있어야 한다. 25번부터 28번까지는 알고리즘이 잘 보이도록 예제를 Python으로 쓴다.

    이 항목에서 배우는 것¶

    • 꼭짓점과 간선, 무향과 방향, 가중치를 구분해 그래프를 그릴 수 있다.
    • 같은 그래프를 인접 행렬과 인접 리스트로 만들고 서로 바꿀 수 있다.
    • 질문의 종류와 간선의 수를 보고 어느 표현이 맞는지 고를 수 있다.

    1. 그래프는 점과 선이다¶

    • 그래프는 꼭짓점(vertex, 점)과 그 사이를 잇는 간선(edge, 선)으로 이루어진다. 꼭짓점 수를 V, 간선 수를 E라 쓴다.
    • 간선에 방향이 없으면 무향 그래프, 있으면 방향 그래프다. 간선마다 거리나 시간 같은 값이 붙으면 가중치 그래프다.
    • 트리(23번(트리와 이진 탐색 트리))도 그래프다. 사이클(돌아오는 길)이 없고 모든 꼭짓점이 이어진 그래프를 트리라 한다.

    2. 행렬은 "이어졌나?"를, 리스트는 "이웃은 누구?"를 바로 답한다¶

    직접 해 보기인접 행렬과 인접 리스트행렬 칸을 눌러 간선을 넣고 빼며 그림·행렬·리스트가 함께 바뀌는 것을 보고, 꼭짓점을 골라 '이웃은?'과 '이어졌나?'에 두 표현이 몇 칸을 보는지 비교한다
    새 창에서 크게 열기 
    n = 6
edges = [(0, 1), (0, 2), (1, 2), (1, 3), (3, 4), (4, 5)]

matrix = [[0] * n for _ in range(n)]     # n × n칸, 처음엔 모두 0
adj = [[] for _ in range(n)]             # 꼭짓점마다 빈 이웃 목록
for u, v in edges:
    matrix[u][v] = matrix[v][u] = 1      # 무향이라 양쪽 다
    adj[u].append(v)
    adj[v].append(u)

print(matrix[1][3])   # 1
print(adj[1])         # [0, 2, 3]
    • 인접 행렬은 V × V칸 표의 [u][v] 칸에 간선이 있으면 1을 쓴다. "u와 v가 이어졌나?"는 한 칸만 보면 되지만(O(1)), "u의 이웃은?"은 u의 행 V칸을 모두 봐야 한다(O(V)).
    • 인접 리스트는 꼭짓점마다 이웃 목록만 둔다. "u의 이웃은?"은 이웃 수만큼만 보면 된다. "이어졌나?"는 목록을 훑어야 하지만 이웃이 적으면 금방이다.
    • 가중치 그래프는 행렬 칸에 1 대신 가중치를, 리스트에는 (이웃, 가중치) 짝을 넣는다.

    3. 간선이 드물면 리스트가 훨씬 작고 빠르다¶

    • 행렬은 간선이 몇 개든 V²칸을 차지한다. 리스트는 꼭짓점마다 목록이 하나(V)이고 무향 간선은 양쪽 목록에 한 번씩(2E) 적으니 V + 2E칸, 곧 O(V + E)다. 실제 그래프는 대부분 이웃이 몇 개뿐이라(SNS에서 한 사람의 친구는 전체 사용자의 아주 일부다) 리스트가 훨씬 작다.
    • 꼭짓점 4,000개에 이웃이 평균 10개인 그래프에서 행렬은 128MB, 리스트는 0.68MB였다. 모든 이웃을 훑는 일도 행렬이 약 200배 느렸다. "이어졌나?"를 10만 번 묻는 데는 둘 다 약 10ms로 비슷했다. 이웃이 10개뿐이라 리스트를 훑어도 금방 끝났기 때문이다.
    • 그래서 그래프 탐색(27번(그래프 탐색 (DFS·BFS)))과 대부분의 그래프 알고리즘은 인접 리스트를 쓴다. 행렬은 꼭짓점이 적고 간선이 빽빽하거나, "이어졌나?"를 아주 많이 물을 때 고른다.

    예측해 보기¶

    문제 1. 3 × 3 행렬을 짧게 만들고 한 칸을 바꿨다. 무엇이 출력될까?

    grid = [[0] * 3] * 3
grid[0][1] = 1
print(grid)
    정답과 해설

    [[0, 1, 0], [0, 1, 0], [0, 1, 0]]. [0] * 3은 새 목록 하나를 만들지만, 그것을 * 3하면 같은 목록을 가리키는 참조 세 개가 생긴다(10번(메모리 참조의 본질)의 참조). 세 줄이 같은 목록이라 한 칸을 바꾸면 모든 줄이 바뀌어 보인다. 2절처럼 [[0] * n for _ in range(n)]으로 줄마다 새 목록을 만들어야 한다. AI가 짠 행렬 코드에서도 자주 보이는 실수다.

    문제 2. 방향 그래프인 팔로우 관계에서, 각 사람을 팔로우하는 사람 목록을 만든다. 무엇이 출력될까?

    follows = {"A": ["B", "C"], "B": ["C", "A"], "C": ["A"], "D": ["A"]}
followers = {name: [] for name in follows}
for u, vs in follows.items():
    for v in vs:
        followers[v].append(u)
print(followers["A"])
print(len(follows["A"]), len(followers["A"]))
    정답과 해설 
    ['B', 'C', 'D']
2 3

    A를 가리키는 간선은 B→A, C→A, D→A다. A가 팔로우하는 사람은 2명(나가는 간선)인데 A의 팔로워는 3명(들어오는 간선)이다. 방향 그래프에서는 이 둘을 따로 센다. 들어오는 쪽을 자주 물으면, 이렇게 거꾸로 된 리스트를 하나 더 만들어 둔다.

    직접 해보기¶

    실습: AI 없이 두 표현 다루기

    1. 인접 행렬을 받아 인접 리스트를 돌려주는 matrix_to_adj와, 반대로 바꾸는 adj_to_matrix를 짠다. 2절의 그래프로 확인한다.
    2. 무향 그래프에서 꼭짓점 u의 "친구의 친구"를 구한다. u 자신과, 이미 u와 이어진 꼭짓점은 뺀다. 2절의 그래프에서 0의 친구의 친구를 구한다.
    3. 인접 행렬이 무향 그래프인지(대칭인지) 검사하는 is_undirected를 짠다.
    정답

    예시. 2절에서 만든 matrix와 adj를 그대로 쓴다.

    def matrix_to_adj(m):
    return [[v for v in range(len(m)) if m[u][v]] for u in range(len(m))]

def adj_to_matrix(a):
    m = [[0] * len(a) for _ in range(len(a))]
    for u, vs in enumerate(a):
        for v in vs:
            m[u][v] = 1
    return m

def friends_of_friends(a, u):
    result = set()
    for f in a[u]:
        result.update(a[f])
    return sorted(result - set(a[u]) - {u})

def is_undirected(m):
    return all(m[u][v] == m[v][u] for u in range(len(m)) for v in range(len(m)))

print(matrix_to_adj(matrix)[1])           # [0, 2, 3]
print(adj_to_matrix(adj) == matrix)       # True
print(friends_of_friends(adj, 0))         # [3]
print(is_undirected(matrix))              # True
    • matrix_to_adj가 만든 목록은 꼭짓점 번호 차례다. 2절의 adj는 간선을 넣은 차례라 순서가 다를 수 있지만, 이웃의 모음은 같다.
    • 0의 이웃은 1과 2다. 1의 이웃 0, 2, 3과 2의 이웃 0, 1을 모으면 0, 1, 2, 3이고, 여기서 0 자신과 이미 친구인 1, 2를 빼면 3이 남는다.

    AI와 함께 확인하기¶

    AI 활용 과제: 이름으로 된 그래프 만들기

    1. AI에게 "사람 이름 목록과 친구 관계 목록을 받아, 무향 그래프의 인접 리스트(dict)를 만드는 Python 함수"를 짜 달라고 한다.
    2. 이름 ["kim", "lee", "park", "choi"], 관계 [("kim", "lee"), ("lee", "choi"), ("kim", "lee")]로 결과를 먼저 적는다. park은 친구가 없고, 마지막 관계는 첫 관계와 같다.
    3. 실행해 대조하고, 다르면 이 입력을 보여 주고 고치게 한다.
    확인할 점
    • 결과는 {'kim': ['lee'], 'lee': ['kim', 'choi'], 'park': [], 'choi': ['lee']}여야 한다.
    • 관계 목록만 보고 dict를 만들면 친구가 없는 park이 빠진다. 나중에 graph["park"]에서 KeyError가 난다.

    • 무향인데 한쪽 방향만 넣는 실수, 같은 관계를 두 번 넣어 이웃이 겹치는 실수가 흔하다. 겹침은 이웃을 set으로 두거나 넣기 전에 확인해서 막는다.

      def build_graph(names, pairs):
    g = {name: [] for name in names}      # 친구가 없어도 빈 목록으로
    for a, b in pairs:
        if b not in g[a]:                 # 같은 관계를 두 번 넣지 않는다
            g[a].append(b)
            g[b].append(a)
    return g

g = build_graph(["kim", "lee", "park", "choi"], [("kim", "lee"), ("lee", "choi"), ("kim", "lee")])
print(g)   # {'kim': ['lee'], 'lee': ['kim', 'choi'], 'park': [], 'choi': ['lee']}

    더 알아보기¶

    이 항목의 측정 프로그램

    3절의 값은 아래 프로그램을 이 PC(Core i9-14900KF, DDR5 64GB)의 Python 3.14로 3번 실행한 결과다. 메모리는 tracemalloc으로 표현을 만드는 동안 늘어난 양을 쟀다. 간선은 같은 씨앗(seed)으로 만든 무작위 간선이라 세 번 모두 같은 그래프다.

    import random
import time
import tracemalloc

def make_edges(n, m, seed=25):
    rnd = random.Random(seed)
    seen = set()
    while len(seen) < m:
        u, v = rnd.randrange(n), rnd.randrange(n)
        if u != v:
            seen.add((min(u, v), max(u, v)))
    return sorted(seen)

def build_matrix(n, edges):
    mat = [[0] * n for _ in range(n)]
    for u, v in edges:
        mat[u][v] = mat[v][u] = 1
    return mat

def build_list(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    return adj

def measure(build, n, edges):
    tracemalloc.start()
    g = build(n, edges)
    cur, _ = tracemalloc.get_traced_memory()
    tracemalloc.stop()
    return g, cur

for n in (1000, 2000, 4000):
    edges = make_edges(n, 5 * n)
    mat, mem_m = measure(build_matrix, n, edges)
    adj, mem_l = measure(build_list, n, edges)
    t = time.perf_counter(); s1 = sum(1 for u in range(n) for v in range(n) if mat[u][v]); t1 = time.perf_counter() - t
    t = time.perf_counter(); s2 = sum(1 for u in range(n) for v in adj[u]); t2 = time.perf_counter() - t
    rnd = random.Random(1)
    qs = [(rnd.randrange(n), rnd.randrange(n)) for _ in range(100000)]
    t = time.perf_counter(); c1 = sum(mat[u][v] for u, v in qs); t3 = time.perf_counter() - t
    t = time.perf_counter(); c2 = sum(v in adj[u] for u, v in qs); t4 = time.perf_counter() - t
    assert s1 == s2 == 2 * len(edges) and c1 == c2
    print(f"V={n} E={len(edges)} 행렬 {mem_m / 1e6:.2f}MB 리스트 {mem_l / 1e6:.2f}MB | "
          f"모든 이웃 {t1 * 1000:.1f}ms / {t2 * 1000:.2f}ms | 이어졌나 10만 번 {t3 * 1000:.1f}ms / {t4 * 1000:.1f}ms")

    정리¶

    • 그래프는 꼭짓점과 간선이다. 방향이 있으면 방향 그래프, 간선에 값이 붙으면 가중치 그래프다.
    • 인접 행렬은 V²칸에 "이어졌나"를 적어 그 질문에 O(1)로 답한다. 인접 리스트는 이웃만 적어 V + 2E칸(O(V + E))에 담고 이웃을 빨리 훑는다.
    • 실제 그래프는 대부분 간선이 드물어서 인접 리스트를 쓴다. Python에서 행렬을 만들 때는 [[0] * n for _ in range(n)]로 줄마다 새 목록을 만든다.

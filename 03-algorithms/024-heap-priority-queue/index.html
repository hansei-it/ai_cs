    24. 힙(Heap)의 원리와 우선순위 큐¶

    직접 AI 없이 직접 할 수 있어야 하는 항목

    큐는 먼저 들어온 것부터 꺼냈다(21번(선형 자료구조)). 응급실, 운영체제의 작업 스케줄러, 길 찾기처럼 "지금 가장 급한 것"부터 꺼내야 하는 곳도 많다. 이것이 우선순위 큐이고, 그 바탕에 흔히 쓰는 자료구조가 힙이다. 힙은 트리지만 포인터 없이 배열 하나에 담는다. 직접형 항목이므로 힙의 넣기와 꺼내기를 AI 없이 짜고, 배열 칸 번호로 손으로 따라갈 수 있어야 한다. 예제는 C다. (메모리의 힙 영역(11번(힙 메모리 관리))과는 이름만 같고 관계가 없다.)

    이 항목에서 배우는 것¶

    • 힙을 배열에 담는 규칙(부모와 자식의 칸 번호)을 쓰고, 트리 모양과 배열을 오갈 수 있다.
    • 넣기(올라가며 바꾸기)와 꺼내기(내려가며 바꾸기)를 손으로 따라가고 C로 짤 수 있다.
    • 우선순위 큐를 힙으로 만드는 이유를 넣기·꺼내기 비용으로 설명할 수 있다.

    1. 힙은 배열 하나에 담은 완전 이진 트리다¶

    • 최소 힙은 모든 부모가 두 자식보다 작거나 같은 이진 트리다. 그래서 가장 작은 값이 늘 뿌리(0번 칸)에 있다. 크고 작음을 바꾸면 최대 힙이다.
    • BST(23번(트리와 이진 탐색 트리))처럼 왼쪽과 오른쪽에 규칙이 있지는 않다. 부모와 자식 사이만 지킨다.
    • 층을 위에서부터, 한 층 안에서는 왼쪽부터 빈틈없이 채운다(완전 이진 트리). 그래서 포인터 없이 배열에 담고 칸 번호 계산으로 부모와 자식을 찾는다. 높이는 늘 log n 남짓이다.

    2. 넣기는 올라가며, 꺼내기는 내려가며 바꾼다¶

    직접 해 보기힙 실험실값을 넣고 가장 작은 값을 꺼내며, 배열 칸과 트리 모양에서 부모와 자식을 바꾸는 과정을 한 단계씩 넘겨 본다
    새 창에서 크게 열기 
    #define MAXN 100

int heap[MAXN];
int size = 0;

void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}

int push(int v) {
    if (size == MAXN)
        return 0;
    int i = size++;
    heap[i] = v;                                     /* 맨 끝에 놓고 */
    while (i > 0 && heap[(i - 1) / 2] > heap[i]) {   /* 부모보다 작으면 올라간다 */
        swap(&heap[(i - 1) / 2], &heap[i]);
        i = (i - 1) / 2;
    }
    return 1;
}

int pop(int *out) {
    if (size == 0)
        return 0;
    *out = heap[0];                                  /* 가장 작은 값 */
    heap[0] = heap[--size];                          /* 맨 끝 값을 뿌리로 옮기고 */
    int i = 0;
    for (;;) {                                       /* 더 작은 자식과 바꾸며 내려간다 */
        int l = 2 * i + 1, r = 2 * i + 2, m = i;
        if (l < size && heap[l] < heap[m])
            m = l;
        if (r < size && heap[r] < heap[m])
            m = r;
        if (m == i)
            break;
        swap(&heap[m], &heap[i]);
        i = m;
    }
    return 1;
}
    • 넣을 때는 맨 끝 칸에 놓고, 부모보다 작으면 자리를 바꾸며 올라간다. 꺼낼 때는 뿌리를 꺼내고 맨 끝 값을 뿌리로 옮긴 뒤, 두 자식 중 더 작은 쪽과 바꾸며 내려간다.
    • 어느 쪽이든 한 층에 한 번만 바꾸므로 많아야 높이만큼, O(log n)이다. 가장 작은 값을 보기만 하는 것은 O(1)이다.

    3. 우선순위 큐는 힙으로 만든다¶

    • 정렬된 배열로 우선순위 큐를 만들면 꺼내기는 O(1)이지만 넣을 때마다 자리를 찾아 밀어야 해서 O(n)이다. 정렬하지 않은 배열은 넣기가 O(1)이지만 꺼낼 때마다 가장 작은 값을 찾아 훑어야 해서 O(n)이다.
    • 힙은 둘 다 O(log n)이다. 10만 개를 넣고 모두 꺼내는 데 힙은 5.4~6.4ms, 정렬된 배열은 533~559ms, 정렬하지 않은 배열은 6.9~7.0초가 걸렸다.
    • 운영체제의 작업 스케줄러(32번(CPU 스케줄링과 컨텍스트 스위칭)), 최단 경로를 찾는 다익스트라 알고리즘, "가장 큰 k개 고르기"가 힙을 쓴다. C#은 PriorityQueue<TElement, TPriority>, Python은 heapq로 힙을 준다.

    예측해 보기¶

    문제 1. 배열에 담은 힙에서 5번 칸의 부모와 두 자식은 몇 번 칸일까?

    정답과 해설

    부모는 2번, 자식은 11번과 12번이다. 부모는 (5 − 1) / 2 = 2(정수 나눗셈), 자식은 2 × 5 + 1 = 11과 2 × 5 + 2 = 12다. 2번 칸의 자식이 5번과 6번이니 거꾸로 맞는지도 확인할 수 있다.

    문제 2. 2절의 push와 pop으로 무엇이 출력될까? 위젯에 같은 값을 넣어 단계마다 확인한다.

    int x;
push(5);
push(3);
push(8);
push(1);
for (int i = 0; i < size; i++)
    printf("%d ", heap[i]);
printf("\n");
pop(&x);
printf("%d\n", x);
for (int i = 0; i < size; i++)
    printf("%d ", heap[i]);
printf("\n");
    정답과 해설 
    1 3 8 5
1
3 5 8

    3은 넣자마자 부모 5보다 작아 뿌리로 올라간다(3 5). 8은 그대로 2번 칸(3 5 8). 1은 3번 칸에 놓인 뒤 부모 5, 다시 부모 3과 바꿔 뿌리까지 올라간다(1 3 8 5). 꺼낼 때는 1을 꺼내고 맨 끝 5를 뿌리로 옮긴 뒤, 두 자식 3과 8 중 작은 3과 바꾼다(3 5 8). 배열이 정렬된 차례는 아니지만 힙 조건은 지킨다.

    직접 해보기¶

    실습: AI 없이 힙 쓰기

    1. 2절의 힙에 값을 모두 넣었다가 모두 꺼내면 정렬된 차례가 된다(힙 정렬). 7, 2, 9, 4, 11, 5, 8로 확인한다.
    2. 값 n개 가운데 가장 큰 k개를 고른다. 크기 k짜리 최소 힙을 두고, 새 값이 힙의 뿌리(지금까지 고른 k개 중 가장 작은 값)보다 크면 뿌리를 꺼내고 새 값을 넣는다. 1번과 같은 값에서 k = 3으로 해 본다. 왜 O(n log k)인지 적는다.
    3. 비교 방향만 바꿔 최대 힙을 만든다.
    정답

    예시. 1번과 2번을 한 프로그램으로 확인한다.

    #include <stdio.h>

#define MAXN 100

int heap[MAXN];
int size = 0;

void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}

int push(int v) {
    if (size == MAXN)
        return 0;
    int i = size++;
    heap[i] = v;
    while (i > 0 && heap[(i - 1) / 2] > heap[i]) {
        swap(&heap[(i - 1) / 2], &heap[i]);
        i = (i - 1) / 2;
    }
    return 1;
}

int pop(int *out) {
    if (size == 0)
        return 0;
    *out = heap[0];
    heap[0] = heap[--size];
    int i = 0;
    for (;;) {
        int l = 2 * i + 1, r = 2 * i + 2, m = i;
        if (l < size && heap[l] < heap[m])
            m = l;
        if (r < size && heap[r] < heap[m])
            m = r;
        if (m == i)
            break;
        swap(&heap[m], &heap[i]);
        i = m;
    }
    return 1;
}

int main(void) {
    int vals[] = { 7, 2, 9, 4, 11, 5, 8 };
    int n = 7, x;
    for (int i = 0; i < n; i++)                  /* 1. 힙 정렬 */
        push(vals[i]);
    while (pop(&x))
        printf("%d ", x);
    printf("\n");
    for (int i = 0; i < n; i++) {                /* 2. 가장 큰 3개 */
        if (size < 3)
            push(vals[i]);
        else if (vals[i] > heap[0]) {
            pop(&x);
            push(vals[i]);
        }
    }
    while (pop(&x))
        printf("%d ", x);
    printf("\n");
    return 0;
}

    2 4 5 7 8 9 11
8 9 11
    • 2는 값 n개마다 크기 k인 힙에 많아야 넣기·꺼내기를 한 번씩 해서 O(n log k)다. 전부 정렬하면 O(n log n)이니, n이 아주 크고 k가 작을 때 훨씬 빠르고 메모리도 k칸이면 된다.
    • 3은 값끼리 비교하는 세 곳만 방향을 바꾼다. push의 heap[(i - 1) / 2] > heap[i]를 <로, pop의 heap[l] < heap[m]과 heap[r] < heap[m]을 >로 바꾸면 뿌리에 가장 큰 값이 있다. 칸 번호를 비교하는 i > 0, l < size, r < size는 그대로 둔다.

    AI와 함께 확인하기¶

    AI 활용 과제: 꺼내기 함수 시험하기

    1. AI에게 "배열로 만든 최소 힙에서 가장 작은 값을 꺼내는 C 함수"를 짜 달라고 한다.
    2. 1, 8, 3, 9, 10, 4를 차례로 넣은 힙에서 모두 꺼낼 때의 결과를 먼저 적는다.
    3. AI의 함수로 실행해 대조한다. 정렬된 차례가 아니면 이 입력을 보여 주고 고치게 한다.
    확인할 점
    • 결과는 1 3 4 8 9 10이어야 한다. 이 힙은 [1, 8, 3, 9, 10, 4]라서, 1을 꺼낸 뒤 뿌리로 온 4의 두 자식 중 오른쪽(3)이 더 작다. 왼쪽 자식만 보는 코드는 4를 그 자리에 두어 힙이 깨지고, 다음에 3이 아니라 4가 나온다.
    • 0번 칸부터 쓰면서 자식을 2i, 2i+1로 구하는 코드는 1번 칸부터 쓰는 책의 공식을 그대로 옮긴 것이다. 뿌리의 자식이 0번 자신이 된다.
    • 자식이 왼쪽 하나뿐인 칸에서 오른쪽 칸(r)을 size와 비교하지 않고 읽는지 본다. 이미 꺼낸 값이 남아 있는 칸을 읽게 된다.

    더 알아보기¶

    이 항목의 측정 방법

    3절의 값은 0 이상 10억 미만의 무작위 정수 n개를 넣고 모두 꺼내며, 꺼낸 값이 작은 차례로 나오는지도 확인한 시간이다. 이 PC(Core i9-14900KF, DDR5 64GB)에서 아래 프로그램을 cl /O2로 빌드해 경우마다 5번 실행했다. 정렬된 배열은 큰 값부터 작은 값 차례로 두어 맨 끝에서 꺼내고, 넣을 자리는 뒤에서부터 찾아 memmove로 민다. 정렬하지 않은 배열은 맨 끝에 넣고, 꺼낼 때 전체를 훑어 가장 작은 값을 찾은 뒤 그 자리에 맨 끝 값을 옮긴다. ok=1은 꺼낸 값이 작은 차례로 나왔다는 뜻이다.

    /* 24번 측정: 우선순위 큐 세 가지 - n개를 넣고 가장 작은 것부터 모두 꺼내는 시간
   usage: pq.exe <0 힙 | 1 정렬된 배열 | 2 정렬 안 한 배열> <n> */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <windows.h>

static unsigned int seed = 24;
static unsigned int rnd(void) { seed ^= seed << 13; seed ^= seed >> 17; seed ^= seed << 5; return seed; }
static double now_ms(void) {
    static LARGE_INTEGER f; LARGE_INTEGER c;
    if (!f.QuadPart) QueryPerformanceFrequency(&f);
    QueryPerformanceCounter(&c);
    return (double)c.QuadPart * 1000.0 / (double)f.QuadPart;
}

static int *a; static int size;

static void heap_push(int v) {
    int i = size++;
    a[i] = v;
    while (i > 0 && a[(i - 1) / 2] > a[i]) { int p = (i - 1) / 2, t = a[p]; a[p] = a[i]; a[i] = t; i = p; }
}
static int heap_pop(void) {
    int top = a[0];
    a[0] = a[--size];
    int i = 0;
    for (;;) {
        int l = 2 * i + 1, r = l + 1, m = i;
        if (l < size && a[l] < a[m]) m = l;
        if (r < size && a[r] < a[m]) m = r;
        if (m == i) break;
        int t = a[m]; a[m] = a[i]; a[i] = t; i = m;
    }
    return top;
}
static void sorted_push(int v) {               /* 큰 것부터 작은 것 차례로 둔다: 맨 끝이 가장 작다 */
    int i = size;
    while (i > 0 && a[i - 1] < v) i--;
    memmove(a + i + 1, a + i, (size - i) * sizeof(int));
    a[i] = v; size++;
}
static int sorted_pop(void) { return a[--size]; }
static void plain_push(int v) { a[size++] = v; }
static int plain_pop(void) {
    int m = 0;
    for (int i = 1; i < size; i++) if (a[i] < a[m]) m = i;
    int v = a[m]; a[m] = a[--size];
    return v;
}

int main(int argc, char **argv) {
    int mode = atoi(argv[1]), n = atoi(argv[2]);
    a = malloc(sizeof(int) * n); size = 0;
    int *vals = malloc(sizeof(int) * n);
    for (int i = 0; i < n; i++) vals[i] = (int)(rnd() % 1000000000u);
    long long check = 0; int prev = -1, ok = 1;
    double t0 = now_ms();
    for (int i = 0; i < n; i++) { if (mode == 0) heap_push(vals[i]); else if (mode == 1) sorted_push(vals[i]); else plain_push(vals[i]); }
    for (int i = 0; i < n; i++) {
        int v = mode == 0 ? heap_pop() : mode == 1 ? sorted_pop() : plain_pop();
        if (v < prev) ok = 0;
        prev = v; check += v;
    }
    double t1 = now_ms();
    printf("%d n=%d %.1f ms ok=%d %lld\n", mode, n, t1 - t0, ok, check);
    return 0;
}
    n개를 한꺼번에 힙으로 만들기

    n개를 하나씩 넣으면 O(n log n)이지만, 배열 전체를 먼저 놓고 뒤쪽 부모부터 차례로 "내려가며 바꾸기"를 하면 O(n)에 힙이 된다. 아래층에는 노드가 많지만 내려갈 거리가 짧기 때문이다. 제자리에서 하는 힙 정렬은 이렇게 힙을 만든 뒤, 뿌리(최댓값)를 맨 끝과 바꾸고 크기를 하나씩 줄여 가며 내려가기를 되풀이한다.

    정리¶

    • 힙은 부모가 자식보다 작거나 같은(최소 힙) 완전 이진 트리다. 배열에 담고, i번 칸의 자식은 2i+1, 2i+2, 부모는 (i−1)/2번이다.
    • 넣기는 맨 끝에서 올라가며, 꺼내기는 맨 끝 값을 뿌리로 옮긴 뒤 더 작은 자식과 바꾸며 내려간다. 둘 다 O(log n)이다.
    • 우선순위 큐는 힙으로 만든다. 정렬된 배열이나 정렬하지 않은 배열은 넣기와 꺼내기 중 하나가 O(n)이다.
